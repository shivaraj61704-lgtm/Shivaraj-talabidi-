📐 2nd PUC Maths Formula Bank

Important formulas for Board, KCET & JEE revision

1️⃣ Relations & Functions

Composition: (f ∘ g)(x) = f(g(x))

Identity function: f(x) = x

Inverse function: f⁻¹(f(x)) = x

One-one function: f(x₁) = f(x₂) ⇒ x₁ = x₂

Onto function: Range = Codomain

Number of functions from A to B: n(B)n(A)

Number of one-one functions: n(B)! / [n(B) − n(A)]!

2️⃣ Inverse Trigonometric Functions

sin⁻¹x + cos⁻¹x = π/2

tan⁻¹x + cot⁻¹x = π/2

sec⁻¹x + cosec⁻¹x = π/2

tan⁻¹x + tan⁻¹y = tan⁻¹[(x+y)/(1−xy)]

tan⁻¹x − tan⁻¹y = tan⁻¹[(x−y)/(1+xy)]

sin⁻¹x + sin⁻¹y = sin⁻¹[x√(1−y²)+y√(1−x²)]

3️⃣ Matrices

Matrix multiplication: (AB)ij = Σ aikbkj

(AB)T = BTAT

(A + B)T = AT + BT

A A⁻¹ = A⁻¹ A = I

2 × 2 determinant:

|a b|
|c d| = ad − bc

A⁻¹ = adj(A) / |A|

Matrix A is invertible if |A| ≠ 0.

4️⃣ Determinants

|a b|
|c d| = ad − bc

For a 3 × 3 determinant: expand along any row or column.

|kA| = kn|A| for an n × n matrix.

If two rows or columns are identical, determinant = 0.

Interchanging two rows/columns changes the sign of determinant.

Determinant of identity matrix = 1.

5️⃣ Continuity & Differentiability

f(x) is continuous at x = a if:

lim x→a f(x) = f(a)

Left hand limit = Right hand limit = f(a)

Differentiability ⇒ Continuity

Continuity ⇏ Differentiability

6️⃣ Differentiation

d/dx(xⁿ) = nxⁿ⁻¹

d/dx(sin x) = cos x

d/dx(cos x) = −sin x

d/dx(tan x) = sec²x

d/dx(cot x) = −cosec²x

d/dx(sec x) = sec x tan x

d/dx(cosec x) = −cosec x cot x

d/dx(eˣ) = eˣ

d/dx(aˣ) = aˣ log a

d/dx(log x) = 1/x

Product rule:

(uv)' = u'v + uv'

Quotient rule:

(u/v)' = (vu' − uv') / v²

Chain rule:

dy/dx = (dy/du)(du/dx)

7️⃣ Applications of Derivatives

Increasing function: f'(x) > 0

Decreasing function: f'(x) < 0

Critical point: f'(x) = 0

Local maximum: f'(a)=0 and f''(a)<0

Local minimum: f'(a)=0 and f''(a)>0

Slope of tangent = dy/dx

Slope of normal = −1/(dy/dx)

8️⃣ Integrals

∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1

∫1/x dx = log|x| + C

∫eˣ dx = eˣ + C

∫sin x dx = −cos x + C

∫cos x dx = sin x + C

∫sec²x dx = tan x + C

∫cosec²x dx = −cot x + C

∫sec x tan x dx = sec x + C

∫cosec x cot x dx = −cosec x + C

Integration by parts:

∫u dv = uv − ∫v du

9️⃣ Definite Integrals

∫ₐᵇ f(x)dx = F(b) − F(a)

∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx

If f(x) is even: ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx

If f(x) is odd: ∫₋ₐᵃ f(x)dx = 0

🔟 Applications of Integrals

Area under curve = ∫ₐᵇ y dx

Area between two curves = ∫ₐᵇ |f(x) − g(x)| dx

If curve is x = f(y): Area = ∫ₐᵇ x dy

1️⃣1️⃣ Differential Equations

Order = highest order derivative.

Degree = highest power of the highest order derivative after removing radicals/fractions involving derivatives.

Variable separable form: dy/dx = f(x)g(y)

Then: dy/g(y) = f(x)dx

Linear differential equation: dy/dx + Py = Q

Integrating factor: IF = e∫Pdx

1️⃣2️⃣ Vector Algebra

|a| = √(a₁² + a₂² + a₃²)

a · b = |a||b|cosθ

a × b = |a||b|sinθ n̂

a · b = 0 for perpendicular vectors.

a × b = 0 for parallel vectors.

Unit vector: â = a/|a|

i × j = k

j × k = i

k × i = j

1️⃣3️⃣ Three-Dimensional Geometry

Distance between two points:

√[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]

Section formula:

((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n))

Direction cosines: l² + m² + n² = 1

Angle between two lines:

cosθ = l₁l₂ + m₁m₂ + n₁n₂

Equation of a plane: ax + by + cz + d = 0

1️⃣4️⃣ Probability

P(A') = 1 − P(A)

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Conditional probability: P(A|B) = P(A∩B)/P(B)

P(A∩B) = P(A)P(B|A)

For independent events: P(A∩B) = P(A)P(B)

Bayes' theorem:

P(Aᵢ|B) = [P(Aᵢ)P(B|Aᵢ)] / ΣP(Aⱼ)P(B|Aⱼ)

1️⃣ Electric Charges & Fields

Coulomb's law: F = (1/4πε₀) × (q₁q₂/r²)

Electric field: E = F/q

Point charge: E = (1/4πε₀)(q/r²)

Electric dipole moment: p = q × 2a

Dipole field on axial line: E = (1/4πε₀) × 2pr/(r²−a²)²

For r ≫ a: E = (1/4πε₀)(2p/r³)

Dipole field on equatorial line: E = (1/4πε₀)(p/(r²+a²)3/2)

Electric flux: Φ = E A cosθ

Gauss law: Φ = qenclosed/ε₀

2️⃣ Electrostatic Potential & Capacitance

Potential: V = W/q

Point charge: V = (1/4πε₀)(q/r)

Potential energy: U = qV

Dipole potential energy: U = −pE cosθ

Capacitance: C = Q/V

Parallel plate capacitor: C = ε₀A/d

With dielectric: C = Kε₀A/d

Energy stored: U = ½CV² = ½QV = Q²/(2C)

Energy density: u = ½ε₀E²

Series: 1/C = 1/C₁ + 1/C₂ + ...

Parallel: C = C₁ + C₂ + ...

3️⃣ Current Electricity

Current: I = Q/t

Drift current: I = neAvd

Ohm's law: V = IR

Resistance: R = ρL/A

Conductivity: σ = 1/ρ

Electrical power: P = VI = I²R = V²/R

Electrical energy: W = VIt

Series resistance: R = R₁ + R₂ + ...

Parallel resistance: 1/R = 1/R₁ + 1/R₂ + ...

Cell terminal voltage: V = E − Ir

Kirchhoff's junction rule: ΣI = 0

Kirchhoff's loop rule: ΣV = 0

4️⃣ Moving Charges & Magnetism

Magnetic force: F = qvB sinθ

Force on current carrying wire: F = BIL sinθ

Biot-Savart law: dB = (μ₀/4π)(I dl sinθ/r²)

Long straight wire: B = μ₀I/(2πr)

Circular coil centre: B = μ₀NI/(2R)

Force between parallel wires: F/L = μ₀I₁I₂/(2πd)

Charged particle radius: r = mv/(qB)

Cyclotron frequency: f = qB/(2πm)

Magnetic moment: M = NIA

Torque: τ = MB sinθ

5️⃣ Magnetism & Matter

Magnetic dipole moment: M = m(2l)

Torque on magnetic dipole: τ = MB sinθ

Potential energy: U = −MB cosθ

Magnetic field inside solenoid: B = μ₀nI

Magnetic susceptibility: χ = M/H

Relative permeability: μr = 1 + χ

6️⃣ Electromagnetic Induction

Magnetic flux: Φ = BA cosθ

Faraday's law: ε = −dΦ/dt

For N turns: ε = −N(dΦ/dt)

Motional emf: ε = Blv

Self inductance: ε = −L(dI/dt)

Energy in inductor: U = ½LI²

7️⃣ Alternating Current

AC voltage: V = V₀ sinωt

RMS voltage: Vrms = V₀/√2

RMS current: Irms = I₀/√2

Inductive reactance: XL = ωL

Capacitive reactance: XC = 1/(ωC)

Impedance: Z = √[R² + (XL−XC)²]

Power factor: cosφ = R/Z

Average power: P = VrmsIrmscosφ

Resonance: XL = XC

Resonant frequency: f₀ = 1/(2π√LC)

8️⃣ Electromagnetic Waves

Speed of EM wave: c = 1/√(μ₀ε₀)

Wave relation: c = fλ

Electric and magnetic fields: E/B = c

Energy density: u = ½ε₀E²

9️⃣ Ray Optics

Mirror formula: 1/f = 1/v + 1/u

Magnification: m = −v/u

Lens formula: 1/f = 1/v − 1/u

Lens magnification: m = v/u

Lens maker formula: 1/f = (μ−1)(1/R₁−1/R₂)

Power of lens: P = 1/f (f in metres)

Combination of lenses: P = P₁ + P₂

Snell's law: n₁sin i = n₂sin r

Refractive index: n = c/v

Critical angle: sin C = 1/μ

🔟 Wave Optics

Young's fringe width: β = λD/d

Bright fringe: path difference = nλ

Dark fringe: path difference = (2n+1)λ/2

Single slit minima: a sinθ = nλ

Intensity in interference: I = I₁ + I₂ + 2√(I₁I₂)cosφ

1️⃣1️⃣ Dual Nature of Radiation

Photon energy: E = hν = hc/λ

Photon momentum: p = h/λ

Photoelectric equation: Kmax = hν − φ

Stopping potential: eV₀ = Kmax

de Broglie wavelength: λ = h/p

For electron: λ = h/√(2meV)

1️⃣2️⃣ Atoms

Bohr angular momentum: mvr = nh/(2π)

Bohr radius: rn = n²r₁

Energy of hydrogen atom: En = −13.6/n² eV

Rydberg formula: 1/λ = R(1/n₁² − 1/n₂²)

1️⃣3️⃣ Nuclei

Nuclear radius: R = R₀A1/3

Mass-energy relation: E = mc²

Mass defect: Δm = Zmp + Nmn − M

Binding energy: BE = Δmc²

Radioactive decay: N = N₀e−λt

Activity: A = λN

Half-life: T1/2 = 0.693/λ

Mean life: τ = 1/λ

1️⃣4️⃣ Semiconductor Electronics

Conductivity: σ = neμ

Diode current: I = I₀[eeV/kT − 1]

Transistor current: IE = IB + IC

Current gain: β = IC/IB

α = IC/IE

Relation: β = α/(1−α)

3️⃣ Chemical Kinetics

Rate = change in concentration / time

For first order reaction: k = (2.303/t) log(a/(a−x))

First-order half-life: t1/2 = 0.693/k

Arrhenius equation: k = Ae−Eₐ/RT

Log form: log k = log A − Eₐ/(2.303RT)

6️⃣ Coordination Compounds

8️⃣ Alcohols, Phenols & Ethers

9️⃣ Aldehydes, Ketones & Carboxylic Acids

General aldehyde formula: R−CHO

General ketone formula: R−CO−R'

🔟 Amines
