📌 Important Formulas

Matrices

(AB)ᵀ = BᵀAᵀ
(AB)⁻¹ = B⁻¹A⁻¹
A⁻¹ = adj(A) / |A|

Determinants

|a b; c d| = ad − bc
|A| ≠ 0 ⇒ A is non-singular

Differentiation

d/dx (xⁿ) = nxⁿ⁻¹
d/dx (sin x) = cos x
d/dx (cos x) = −sin x
d/dx (eˣ) = eˣ
d/dx (log x) = 1/x

Integration

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫1/x dx = log|x| + C
∫eˣ dx = eˣ + C
∫cos x dx = sin x + C
∫sin x dx = −cos x + C

Vectors

a · b = |a||b| cos θ
|a × b| = |a||b| sin θ

Probability

P(A') = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

📌 Important Formulas

⚡ Electrostatics

F = (1/4πε₀) × (q₁q₂/r²)
E = F/q
V = (1/4πε₀) × (q/r)
C = Q/V
C = ε₀A/d

🔋 Current Electricity

V = IR
R = ρL/A
P = VI = I²R = V²/R

🧲 Moving Charges and Magnetism

F = qvB sinθ
F = BIL sinθ
B = μ₀I/(2πr)
B = μ₀nI

🔄 Electromagnetic Induction

ε = −dΦ/dt
Φ = BA cosθ

〰️ Alternating Current

Vᵣₘₛ = V₀/√2
Iᵣₘₛ = I₀/√2
Xᴸ = ωL
Xᶜ = 1/(ωC)

🔭 Optics

1/f = 1/v − 1/u
m = v/u
n = sin i / sin r

☢️ Modern Physics

E = hf
E = hc/λ
λ = h/p
E = mc²

📝 Board Practice Questions

1. State Coulomb's law and write its mathematical expression.

Coulomb's law states that the electrostatic force between two point charges is directly proportional to the product of their charges and inversely proportional to the square of the distance between them.

F = (1/4πε₀)(q₁q₂/r²)
2. What is the SI unit of capacitance?

The SI unit of capacitance is farad (F).
3. Write the expression for force on a moving charge in a magnetic field.

F = qvB sinθ

📌 Important Formulas

🧪 Solutions

Molarity (M) = moles of solute / volume of solution in L
Molality (m) = moles of solute / mass of solvent in kg
M₁V₁ = M₂V₂

⚡ Electrochemistry

ΔG° = −nFE°
E°cell = E°cathode − E°anode
Q = It

⏱ Chemical Kinetics

Rate = k[A]ⁿ
For first order: k = (2.303/t) log(a/(a−x))
t₁/₂ = 0.693/k

⚗️ Organic Chemistry

Alcohol + Na → Sodium alkoxide + H₂
Aldehyde + [O] → Carboxylic acid
R−NH₂ + HCl → R−NH₃⁺Cl⁻

⚗️ Important Organic Reactions

R−X + KOH(aq) → R−OH + KX
R−X + KOH(alc) → Alkene + KX + H₂O

R−CHO + [O] → R−COOH
R−COOH + R'−OH ⇌ R−COOR' + H₂O
